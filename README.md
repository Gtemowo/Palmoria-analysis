# Palmoria Pay Gap Analysis

## Tools used
- PowerBi (data modeling, DAX, report design)
- Power Query (data transformation)

## Project Overview
- An HR analytics dashboard built for **Palmorial**, analyzing workforce composition, performance ratings, salary structure, and compensation equity — including a dedicated gender pay gap analysis. The report spans 8 pages moving from team/overview context into demographic, performance, and pay-equity deep-dives.

## Report Structure
| Page | Purpose |
|---|---|
| Project Team | Project credits and context |
| Overview | Executive summary of workforce metrics |
| Gender Distribution | Total/female/male employee counts by location and department |
| Employee Ratings | Performance rating distribution across departments |
| Salary Structure | Salary breakdown by location, department, and gender, incl. gender pay gap |
| Salary Regulations | Employees earning above key salary thresholds (e.g. $100K) |
| Bonus | Bonus distribution by rating, department, and location, split by gender |
| Conclusion | Summary insights and recommendations |

## Key Visuals & Techniques
- KPI cards for Total/Female/Male/Concealed Employee counts and salary totals
- **Gender Pay Gap** card — a headline compensation-equity metric
- Pivot tables for salary threshold analysis
- Pie and clustered bar/column charts comparing pay, bonus, and headcount by gender

## What I learned
- How to clean raw data
- How to extract data from other sources
- How to visualize insights in PowerBi
